# Hi, I’m Lior1969

**Turning ideas into useful tools.**

I work on AI agents, security, and automation, while exploring better ways to read papers and handle everyday work. I want to understand why a tool is designed the way it is, how the code works, and what still needs a closer look.

## What I’m working on

- **Agent collaboration** — Keeping tasks, prompts, and work records together so projects are easier to continue.
- **Research and reading tools** — Connecting paper reading, source material, and AI assistance in one practical workflow.
- **Security and verification** — Checking assumptions and evidence so conclusions can be traced and improved.

- [bfs-clicker](https://github.com/8eeth0ven/bfs-clicker) — Explore web interfaces, collect mobile API evidence, and connect it to AI clients.
