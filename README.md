# 你好，我是 Lior1969

**把想法做成能用的工具。**

我关注 AI Agent、安全研究和自动化，也在探索怎样让论文阅读与日常工作更顺手。我想弄懂工具为什么这样设计、代码怎样运行，以及哪些地方还值得追问。

## 我在做什么

- **Agent 协作**：整理任务、提示词和工作记录，让多个项目更容易接着做。
- **研究与阅读工具**：把论文阅读、资料整理和 AI 辅助处理放进连贯的工作流程。
- **安全与验证**：检查假设、核对证据，让结论可以回查，也能继续改进。

## 项目入口

- [bfs-clicker](https://github.com/8eeth0ven/bfs-clicker) — 探索 Web 界面，整理移动应用接口证据，并接入 AI 客户端。
- [agentskills-bridge](https://github.com/8eeth0ven/agentskills-bridge) — 在不同 Agent 工具之间迁移技能，保留资料并核验目标环境。
- [Bilingual Paper Studio](https://github.com/8eeth0ven/bilingual-paper-studio) — 把双语 PDF 阅读、选区讨论与 AI 辅助编辑放在一起。
- [AI for Security Papers](https://github.com/8eeth0ven/AI-for-Security-Paper) — 整理 AI 安全研究论文与评述，保留依据，方便回查。
